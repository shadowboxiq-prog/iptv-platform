# منصة IPTV

واجهة React مع خادم Express وقاعدة SQLite. GitHub يحفظ الكود، لكنه لا يشغّل خادم التطبيق أو قاعدة البيانات.

## التشغيل المحلي

1. ثبّت Node.js 22 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` وضع مفاتيح سرية جديدة في `APP_SECRET_KEY` و`JWT_SECRET`.
4. أنشئ حساب مدير عبر `npm run create-admin`.
5. شغّل `npm run server` وافتح `http://localhost:3000`.

لإنشاء مفتاح التشفير: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.

## البناء

- `npm run build` يبني واجهة الويب داخل `dist`.
- `npm run server` يخدم الواجهة وواجهات API محليًا على المنفذ 3000.

## النشر والتجربة عن بُعد

GitHub Pages يستضيف واجهة ثابتة فقط؛ يحتاج التطبيق إلى خادم Node.js مع تخزين دائم لملف SQLite ومجلد الرفع. لا ترفع `.env` أو قاعدة البيانات أو ملفات الرفع إلى المستودع. عيّن المفاتيح والأسرار من إعدادات الاستضافة، واستخدم HTTPS.

للتجربة المؤقتة عبر GitHub Codespaces، أنشئ Codespace لهذا المستودع. إعداد `.devcontainer` يبني الواجهة، ينشئ مفاتيح محلية، ويشغّل التطبيق على المنفذ 3000 مع إبقائه خاصًا افتراضيًا. أنشئ حساب المدير بنفسك قبل جعل المنفذ عامًا. Codespaces ليس استضافة دائمة؛ قد يتوقف عند الخمول وتُطبق عليه حصص الاستخدام والفوترة حسب حساب GitHub.

قبل نشر الواجهة على الإنترنت، أضف عنوانها إلى `APP_ALLOWED_ORIGINS` في إعدادات الخادم. لا تضع روابط مزودي البث أو بيانات دخولهم في ملفات الواجهة أو إعدادات البناء.

استخدم فقط مصادر بث تملك تصريحًا بعرضها.
